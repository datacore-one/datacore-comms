# Brand Positioning

Creates the foundational positioning documents every other comms activity is
checked against. Without them, campaigns lack focus and content lacks
consistency — which is the failure this command exists to prevent, not a
nice-to-have.

## Command Context

| Question | Answer |
|---|---|
| What does it produce? | BrandScript, Tribe Profile, voice guidelines |
| Which agent does the work? | `brand-positioning-agent` (`:AI:comms:brand:`) |
| Which frameworks? | StoryBrand (Donald Miller), Tribal Marketing (Seth Godin) |
| Where do outputs go? | See **Output paths** below — they are fixed |

**This command existed in `module.yaml` for months and its file did not.** The
agent worked via its tag the whole time, so the capability was real and only the
entry point was missing. Anything reading the manifest believed otherwise.

## Workflow

### Step 1 — Gather the brief

Ask only what you cannot infer from the space. Read `venture.yaml`
(`thesis`, `target_customer`, `positioning`) and `3-knowledge/pages/_core/`
first, then ask for what is genuinely absent:

- What does it do, and by what mechanism?
- Who is it for — narrowly? ("everyone" is not an answer)
- What would they use instead today?
- What is remarkable about it, built in rather than bolted on?

### Step 2 — Delegate

Invoke `brand-positioning-agent` with the brief. It applies:

- **Customer is the hero, the brand is the guide.** Never the other way round.
- **Smallest viable audience.** Define the tribe narrowly; solve deeply.
- **Purple Cow.** Remarkable by design.
- **Sneezers.** Identify who spreads the idea.

### Step 3 — Write to the canonical paths

`SCAFFOLDING.base.md` (DIP-0003) already specifies where these live. Use it,
rather than inventing a location — two ventures that both did this step ended
up with the results in two different shapes because the agent produced prose and
a human chose the path.

| Artefact | Path |
|---|---|
| BrandScript | `1-tracks/comms/positioning/<name>-brandscript.md` |
| Tribe Profile | `1-tracks/comms/positioning/<name>-tribe-profile.md` |
| Voice & tone | `1-tracks/comms/brand/voice.md` |
| Key messages | `1-tracks/comms/messaging.md` |
| Positioning | `3-knowledge/pages/_core/positioning.md` |

### Step 4 — Report

List what was written, and say plainly which of the five are still missing.
`/scaffolding-audit` reports the same gaps with status values
(`missing | stub | draft | reviewed | published`) — a stub generated by an agent
is not a position, and should not be reported as one.

## When to run this

At venture stage 4, and not before. Positioning written for an untested belief
is a quarter spent on the wrong story. If the venture has no validated
hypothesis yet, say so and stop.
